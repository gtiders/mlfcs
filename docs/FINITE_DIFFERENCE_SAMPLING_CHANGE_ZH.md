# MLFCS 4.0 有限差分轨道与采样算法变更

[English](FINITE_DIFFERENCE_SAMPLING_CHANGE.md) | 中文

MLFCS 4.0 修改了对称性约化力常数轨道的发现方法，以及将独立有限差分观测合并到位移
构型的方法。本文记录其数学契约、构型数量变化的原因和当前证据的边界；这些开发细节
不放入面向一般用户的根 README。

## 两项相互独立的变化

### 完整的规范轨道发现

令 `S` 为满足物理周期截断的团簇集合，`canon(c)` 为团簇经过空间群操作、张量轴置换和
周期锚定后的规范代表。正确的代表集合为：

```text
R = {canon(c) | c in S}。
```

一个中间开发实现只保留满足 `c == canon(c)` 的候选。只有当 `S` 对规范化操作闭合时，
该条件才成立。在周期边界附近，特别是存在简并周期像或倾斜晶胞时，一个有效候选的
规范代表可能不会被锚定候选生成器直接生成；要求二者相等会删除整个物理轨道。

当前实现对每个通过截断的候选先进行规范化，再对所得代表去重。这是正确性修复，不是
构型数量优化。在 K4As4Pt2 最大 MIC 截断 FC3 夹具中，错误实现只生成 4160 个构型和
122112 个团簇像；修复后恢复全部 3387 个轨道、77730 个独立参数和 136260 个团簇像。

### 标签对称主元与位移键压缩

对一个轨道，将允许的张量写为：

```text
phi_o = B_o theta_o，
```

其中 `B_o` 的列张成轨道稳定子约束的零空间。MLFCS 首先加入携带相同原子标签的张量轴
交换对称性，再选择独立行 `P_o`，使：

```text
rank(P_o B_o) = columns(B_o)。
```

因此 `P_o B_o` 在不可约参数空间上可逆。合并所有轨道后，块观测映射的秩等于独立参数
总数。这证明了代数可恢复性；算法没有减少基空间、轨道支撑域或真正的物理自由参数。

一个位移构型会返回全部 `3N` 个笛卡尔力分量。对 FC3，固定两个被位移自由度后，可以
同时观测全部响应分量：

```text
Phi[i,a,j,b,k,c] = -d^2 F[i,a] / (d u[j,b] d u[k,c])。
```

多个独立主元行可以共享同一个位移键，只使用不同的受力响应。将这些行按位移键合并，
可以避免重复计算同一结构。K4As4Pt2 FC3 的旧选择包含 1659 个位移键，当前选择包含
1061 个；四点中心混合差分方案因而从 `1659 * 4 = 6636` 个构型变为
`1061 * 4 = 4244` 个构型。两个正确实现都保留 77730 个自由参数和相同的 136260 团簇
支撑域。

## 已经证明和尚未证明的内容

满秩证明精确受力观测可以唯一确定不可约参数：

```text
M theta_1 = M theta_2  =>  theta_1 = theta_2。
```

它不能证明数值条件最优。远端或弱响应可能与 SCF、计算器或消减噪声相当。对由力构造的
`n` 阶中心差分，力噪声大约被放大为 `epsilon_F / h^(n-1)`。旧算法和当前算法都会使用
未被直接位移原子的受力响应，因此都存在这一有限差分通用问题。当前方案更接近最小
满秩观测集合，不能仅凭构型更少就宣称它在所有含噪 DFT 计算中更稳定。

K4As4Pt2 的 pypolymlp 黑盒结果与 6636 构型方案具有几乎相同的 FC3 数值误差，但确定性
势函数验证不能代替含噪 DFT 验证。未来可进一步实现考虑条件数的主元选择，以及可选的
冗余超定观测和残差诊断。

## 影响范围

轨道修复同时影响有限差分与拟合，因为二者共享同一个轨道空间。只有当具体材料和截断
下的旧候选集对规范化不闭合时，结果才会改变。仓库中的 KAsPt 设置（FC2 最大范围、FC3
为 12 bohr、FC4 为 8 bohr）已经与隔离的错误实现逐项比较：轨道像、基、主元和参数数
完全一致，所以这些已有拟合不因本次特定 bug 失效。

由于 `sow()` 顺序和构型数量属于外部受力计算契约，用户不能混用旧版本生成的结构与
4.0 的 `reap()`。跨越此次变更升级时，必须重新生成完整的有序结构列表。
