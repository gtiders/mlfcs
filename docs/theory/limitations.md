# 范围与限制

理论公式有各自的物理前提，软件也只实现其中一部分。阅读各章时，以下区别有助于判断一个计算结果能说明什么。

## 周期性与训练目标

当前模型使用三维全周期结构。带真空层的材料仍按三维周期晶胞描述，不是原生二维电静力学模型。

力常数训练使用位移和原子力，不包含能量、应力，也不自动扣除参考力。相互作用的阶数、体数和距离截断都是模型选择；几何壳层建议不能替代对物理收敛或超胞可辨识性的检查。

## 哪些结果是精确认证的

整数对称作用、整数核和秩可以通过整数恒等式得到认证。这里的“精确”不意味着输入几何、笛卡尔转换或数值求解没有浮点误差。空间群是在指定几何容差下发现的，浮点投影也只能在数值精度内满足约束。

Ewald 求和以连续扩大求和范围后的变化判断收敛，不能把这种检查当作严格的剩余尾项界。完整数值方法见[精确线性代数](advanced/exact-linear-algebra.md)和[长程章节](long-range-electrostatics.md)。

## 长程响应与外部软件

`Harmonic` 和 `SCPH` 当前从参数化原胞力常数计算傅里叶响应。`DipoleEwald` 给出指定超胞中的折叠二阶张量，可以用于该超胞的力计算和导出；它单独不能恢复任意 q 点的解析长程响应。

NaCl 教程中的非解析修正（NAC）由 phonopy 完成，热导率教程由 phono3py 完成。MLFCS 当前没有独立输运求解器，也没有 SSCHA 实现。自洽声子章讨论的是固定晶格上的静态四阶环图近似。

## 尚未采用的求解方式

各章先介绍已有数学物理关系，再说明 MLFCS 采用的表示和数值方法，不把一种表示自动视为学术原创结论。

当前拟合和有限差分仍要求原始轨道参数空间在超胞中结构满秩，没有采用只检查 ASR 自由子空间的较弱准入条件。有限差分的 ASR 是物理参数后投影，不是对原始力观测联合求解约束。旋转修正只处理已说明的 FC2 距离矩，不自动施加一般高阶旋转关系。

SCPH 在空间已启用 ASR 时，将裸 FC2、初值和每轮目标投影到已有声学子空间后混合；未启用时不补建约束。当前仍没有解析长程谐波背景入口。任意 q 长程组合的未实现设计另见[长程动力学](../development/long-range-dynamics.md)。

具体调用方式见[有限差分](../finite-difference-api.md)、[拟合](../fitting-api.md)、[长程力与 Ewald](../ewald-api.md)、[谐波声子](../harmonic-api.md)和 [SCPH](../scph.md)。
