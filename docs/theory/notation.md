# 符号与坐标约定

文中“原胞”及代码中的 `primitive` 命名指模型采用的周期参考胞，不要求它是最小原胞。晶格、位点编号与倒格坐标均相对于用户输入的晶胞定义。


各章会在推导中介绍所需符号。这一页只记录反复出现的坐标、阶数和单位，方便阅读时查阅。轨道基、观测行和声学坐标变换等符号仍在相应章节中定义。

## 实空间与超胞

| 符号 | 含义 |
|---|---|
| $A$ | 原胞晶格矩阵，三行是三个晶格向量 |
| $\mathbf s_i$ | 原胞中第 $i$ 个原子的分数行坐标 |
| $\mathbf n$ | 整数晶格平移；位置为 $\mathbf r=(\mathbf s_i+\mathbf n)A$ |
| $N$ | 原胞原子数 |
| $S$ | 整数超胞矩阵，满足 $A_s=SA$ |
| $D_S$ | 超胞平移类的数目，$D_S=|\det S|$ |
| $N_s$ | 超胞原子数，$N_s=ND_S$ |

位置采用行向量。张量分量的变换则使用列形式：若笛卡尔行向量旋转为 $Q_g$，作用在张量每个指标上的矩阵便是 $Q_g^{\mathsf T}$。分数坐标中的整数旋转与笛卡尔旋转的关系见[对称性章节](symmetry-parameterization.md)。

## 力常数与频率

| 符号 | 含义 |
|---|---|
| $p$、$\Phi^{(p)}$ | 位移导数的次数和对应力常数张量 |
| $b_p$ | 第 $p$ 阶允许的最大体数，即不同周期原子位置数 |
| $q$ | 原胞倒格基中的分数行坐标 |
| $\ell$、$G$ | 有限 q 网格的整数标签，以及整数倒格矢位移 |
| $D(q)$ | 质量加权动力学矩阵；不要与超胞大小 $D_S$ 混淆 |
| $\omega$、$f_\nu$ | 角频率与普通频率，后者满足 $f_\nu=\omega_\nu/(2\pi)$ |

长度和位移使用 Å，能量使用 eV，力使用 eV/Å。第 $p$ 阶力常数的单位是 eV/Å$^p$，本身不含 Taylor 阶乘，也不含质量加权。原子质量以 amu 表示，输出的普通声子频率以 THz 表示。

力设计矩阵、物理参数和 ASR 自由变量在[恢复力常数](reconstruction.md)与[不变性约束](invariance-constraints.md)中分别定义，避免用一个参数符号混指不同坐标。
