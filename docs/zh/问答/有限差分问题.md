# 有限差分问题

## 本页回答什么

覆盖位移数量、带符号构型、sow/reap 顺序、外推和 calculator 使用。

## 如何判断是输入问题还是算法问题？

先验证结构、单位、原子顺序和训练数据，再比较同一 target 表示下的 IFC 或预测力。只有这些一致后，才应检查对称、约束或数值求解器。

## 为什么文件不同但物理结果可能相同？

外部格式允许不同 block 顺序、周期代表和原子排列。必须先按结构标签和整数平移对齐，不能逐行比较文本。

## 什么时候应该停止并修改设置？

出现结构匹配失败、rank deficiency、明显异常残差或目标格式无法表示当前 interaction 时，应修改输入或模型范围，不应忽略错误继续运行。

概念定义在 Concepts，公式和近似在 Theory，具体任务在 How-to，完整调用签名和异常在 Reference。
