# 二阶力常数计算：有限差分与力拟合

二阶力常数 FC2 描述参考结构附近的谐性力响应。MLFCS 提供两条公共路径：

- **有限差分**：程序生成一组对称约化的位移结构，直接计算每个位移结构的力，再由中心差分重建 FC2。
- **力拟合**：准备多个带力的 ASE 结构快照，使用力对 FC2 参数的线性关系做整体最小二乘拟合。

两条路径都返回 `ForceConstants`，因此可以使用同一个 `write_force_constants()` 导出为原生 HDF5、phonopy 或其他支持的格式。

## 选择哪一种方法

| 场景 | 推荐方法 | 原因 |
|---|---|---|
| 只需要谐性 FC2，计算器可以直接运行 | 有限差分 | 位移方案和差分收缩由程序管理，流程简单、可解释 |
| 已经有 MD、随机位移或外部程序快照 | 力拟合 | 可以复用已有结构和力，多个快照共同约束参数 |
| 使用 VASP 等外部程序计算力 | 有限差分的 `sow()`/`reap()` | MLFCS 负责生成任务，外部程序负责计算，最后集中重建 |
| 需要同时拟合 FC2、FC3 或 FC4 | 力拟合 | 在一个 `ForceConstantFitter` 中通过 `orders` 联合拟合 |

无论选择哪一种方法，`primitive` 定义晶体的原胞，`reference` 定义计算和训练所使用的参考超胞。参考超胞中的原子顺序是权威顺序，所有位移结构和力都必须保持该顺序。

## 方法一：有限差分

### 直接运行 ASE calculator

下面的最小例子使用 ASE 的 EMT calculator 计算 Al 的力。EMT 只用于演示 API，不代表真实材料计算的精度。

```python
from ase.build import bulk
from ase.calculators.emt import EMT

from mlfcs import ForceConstantCalculation, build_supercell, write_force_constants

primitive = bulk("Al", "fcc", a=4.05)
reference = build_supercell(primitive, (2, 2, 2))

calculation = ForceConstantCalculation(
    primitive,
    order=2,
    reference=reference,
    cutoff=None,
    displacement=0.01,
)
force_constants = calculation.run(EMT())

write_force_constants(force_constants, "fc2-finite-difference.h5", format="hdf5")
write_force_constants(
    force_constants,
    "FORCE_CONSTANTS_2ND",
    format="phonopy",
    order=2,
)
```

这里的 `displacement=0.01` 的单位是 Å。`cutoff` 控制保留的相互作用空间：正数表示 Å，负整数表示近邻壳层，`None` 使用无歧义的最大周期像半径。真实第一性原理计算中，应通过增大参考超胞和改变 cutoff 检查 FC2 是否收敛，而不能照搬这个演示值。

`run()` 默认使用中心差分，并默认施加声学和规则 ASR。若需要关闭 ASR，可以显式传入 `acoustic_sum_rule=False`。零步长外推是有限差分的可选后端：

```python
force_constants = calculation.run(
    EMT(),
    derivative_backend="extrapolate",
    extrapolation_spacing=0.002,
    extrapolation_side_steps=2,
    extrapolation_degree=1,
)
```

该模式需要显式提供 `extrapolation_spacing`；普通中心差分不应同时传入这些外推参数。

### 使用外部程序计算力

不能在当前 Python 进程中调用 VASP 等程序时，使用 `sow()` 和 `reap()` 将任务拆开：

```python
structures = calculation.sow()
```

`structures` 的顺序就是 `reap()` 的位置顺序。将这些结构写出、交给外部程序计算后，收集为形状为 `(n_configurations, n_reference_atoms, 3)` 的数组：

```python
import numpy as np

forces = np.asarray([
    np.load(f"forces/{index:05d}.npy")
    for index in range(len(structures))
])
force_constants = calculation.reap(forces)
```

如果结果返回顺序不稳定，可以使用结构中的 `mlfcs_configuration_id` 建立映射。`reap()` 也接受以该 ID 为键的字典：

```python
forces_by_id = {
    atoms.info["mlfcs_configuration_id"]: np.load(
        f"forces/{atoms.info['mlfcs_configuration_id']:05d}.npy"
    )
    for atoms in structures
}
force_constants = calculation.reap(forces_by_id)
```

程序会检查缺失 ID、力数组形状、非有限值和原子顺序。不要在外部收集力后自行排序或删除结构，否则差分力可能对应错误的位移构型。

## 方法二：仅力数据拟合

力拟合不需要程序生成正负位移。它接收带有力的 ASE `Atoms` 快照，并在指定的 FC2 参数空间中整体拟合。下面的例子用 EMT 生成 24 个随机位移快照；真实使用时，通常把这部分替换为 `ase.io.read("train.extxyz", index=":")`。

```python
import numpy as np
from ase.build import bulk
from ase.calculators.emt import EMT

from mlfcs import build_supercell, write_force_constants
from mlfcs.fitting import ForceConstantFitter

primitive = bulk("Al", "fcc", a=4.05)
reference = build_supercell(primitive, (2, 2, 2))

rng = np.random.default_rng(7)
training = []
for _ in range(24):
    snapshot = reference.copy()
    snapshot.positions += rng.normal(
        loc=0.0,
        scale=0.01,
        size=snapshot.positions.shape,
    )
    snapshot.calc = EMT()
    snapshot.get_forces()
    training.append(snapshot)

fitter = ForceConstantFitter(
    primitive,
    reference,
    orders=(2,),
    cutoffs={2: 5.4},
    max_body_orders={2: 2},
)
result = fitter.fit(
    training,
    validation_split=0.1,
    acoustic_sum_rule=True,
    cache_directory="fit-cache",
)

write_force_constants(result.force_constants, "fc2-fit.h5", format="hdf5")
write_force_constants(
    result.force_constants,
    "FORCE_CONSTANTS_2ND",
    format="phonopy",
    order=2,
)
```

拟合要求所有快照拥有相同的晶格、原子数、原子标签和原子顺序。程序只使用力，不使用能量；如果从文件读取快照，文件中的每个 `Atoms` 必须已经携带 ASE calculator 结果或可用的 `forces` 数组。参考结构的力会被视为参考残余力并从训练目标中扣除。

`cutoffs={2: 5.4}` 和 `max_body_orders={2: 2}` 定义 FC2 的拟合空间。有限差分对应的参数是 `cutoff` 和 `max_body_order`；两条路径应使用一致的参考超胞、截断和体数范围，结果才具有可比性。`validation_split` 用于从快照中留出验证集；快照很少时可以显式设置为 `0.0`，但应另外保留独立测试数据。

默认 `regularization=None` 是严格的无正则拟合。需要轨道组稀疏化时，可以显式设置 `regularization="scaled_group_lasso"`，但仍应检查 `result.diagnostics` 中的收敛和力误差，再导出结果。

## 结果检查与导出

两种方法都可以先检查阶数和元数据：

```python
print(force_constants.orders)
print(force_constants.metadata)
```

拟合结果中的力常数位于 `result.force_constants`，而拟合参数和收敛信息分别保留在结果对象的其他字段中。输出格式由 writer 显式指定：

```python
write_force_constants(force_constants, "fc2.h5", format="hdf5")
write_force_constants(force_constants, "FORCE_CONSTANTS_2ND", format="phonopy", order=2)
```

原生 HDF5 保存 MLFCS 的稀疏 exact-$R$ 表示；phonopy 输出需要将结果写成下游程序理解的 FC2 格式。若目标超胞不同，应先显式调用 `realize_force_constants()`，不要直接把原参考超胞的数组当作另一个超胞使用。

## 常见问题

### 位移量应该多大

位移过小会放大力的数值噪声，过大则会引入非谐项。对第一性原理计算，建议比较多个位移量，并检查 FC2 和声子频率的稳定性。对有限差分，还应同时检查参考超胞和 cutoff 的收敛性。

### 为什么拟合结果和有限差分不一致

常见原因包括训练分布过窄、拟合空间不同、参考超胞原子顺序不一致、未处理参考残余力、有限差分位移过大，以及两个流程使用了不同的 ASR 设置。先统一 `primitive`、`reference`、cutoff、体数和单位，再比较力误差与 FC2 张量。

### 是否可以冻结已有 FC2 再拟合更高阶

不能。MLFCS 的高阶力拟合要求所有阶数在同一个 Wick 参数空间中联合确定；如果只计算 FC2，使用 `orders=(2,)` 即可。更多高阶拟合见[仅力数据的力常数拟合](仅力数据的力常数拟合.md)。

有限差分的完整 API 见[有限差分 API](../参考/有限差分API.md)，拟合器的参数和诊断见[拟合 API](../参考/拟合API.md)。
