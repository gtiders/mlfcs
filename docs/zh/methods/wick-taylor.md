# Wick 收缩与 Taylor 跨阶污染

[English] | 中文

## 要澄清的问题

MLFCS 联合拟合 FC2--FCn 时使用协方差正交化的 Wick 多项式，输出前再转换为参考结构处
的普通 Taylor 力常数。因此，包含 FC4 时会出现

```text
FC2_T = FC2_W - 1/2 FC4_W:Sigma + 1/8 FC6_W:Sigma:Sigma - ...
```

这看起来很像“高阶项进入低阶项”。它与普通 Taylor 回归中的跨阶污染有关，但不是同一
件事：前者是精确、确定性的基变换，后者是有限数据估计中的混淆或偏差。

## 为什么 FC4 会出现在 Taylor FC2 中

以一维四阶 Wick 多项式为例：

```text
H4(x; sigma^2) = x^4 - 6 sigma^2 x^2 + 3 sigma^4
```

若能量按通常的阶乘约定写为

```text
E = FC2_W H2 / 2! + FC4_W H4 / 4! + ...
```

展开回普通位移幂后，`H4` 自带一个二次项，于是参考点的 Taylor 二阶导数为

```text
FC2_T = FC2_W - FC4_W sigma^2 / 2.
```

多维情况下，`sigma^2` 变成超胞位移协方差 `Sigma`，乘法变成原子和笛卡尔指标的张量
收缩。FC6 还能收缩到 FC4、FC2，奇数阶则按相同奇偶层级收缩，例如 FC3 到 FC1。

这里没有再次拟合、迭代修正或把 FC4 的物理作用随意塞进 FC2。Wick 系数和 Taylor
系数是同一截断多项式在两组坐标中的表示；换基前后的能量和力在该多项式空间内相同。
物理 IFC 的定义是参考结构处的 Taylor 导数，所以公共 `ForceConstants` 和外部 writer
必须输出换基后的 Taylor 张量。

## 真正的 Taylor 跨阶污染

普通 Taylor 力特征依次类似于 `x`、`x^2`、`x^3`。有限采样中这些列往往强相关。如果
真实力含有三次位移贡献，却只用线性特征拟合，遗漏的 FC4 贡献会投影到 FC2；即使同时
拟合 FC2 和 FC4，有限样本、噪声、病态设计矩阵、截断和正则化也会使两阶互相补偿。
这才是通常所说的跨阶污染。

Taylor 基本身并不必然产生污染。若模型阶数完整、设计矩阵满秩、数据无噪声且求解精确，
Taylor 联合回归同样能恢复唯一的 Taylor 系数。实际问题来自统计可辨识性，而不是 Taylor
展开的代数定义。

Wick 特征在与 `Sigma` 一致的理想高斯分布下使不同次数正交，因此减少相邻同奇偶阶的
列相关和有限样本互相吸收；对非高斯、有限或不对称数据，这种解耦只是改善而非保证。
最高拟合阶、空间 cutoff 或作用体数不完整时，Wick 基也不能创造缺失的物理相互作用。

## 两者的类同与区别

| 问题 | Wick→Taylor 收缩 | Taylor 跨阶污染 |
|---|---|---|
| 本质 | 同一多项式的精确坐标变换 | 回归中的混淆、方差或偏差 |
| 完美数据下是否存在 | 存在 | 完整满秩模型下可不存在 |
| 是否依赖 `Sigma` | 显式依赖，`Sigma` 定义 Wick 基 | 通过采样分布和设计列相关间接依赖 |
| 是否改变预测多项式 | 不改变 | 通常改变估计出的物理多项式 |
| 增加 FC4 后 FC2 是否可能变化 | Taylor FC2 按换基公式确定性变化 | 估计 FC2 可能因原有遗漏项被释放而变化 |
| 能否靠更多数据消除 | 不能，也不需要消除 | 通常可减轻 |

二者类同之处是都描述了低阶和高阶在有限温度位移分布上的联系，也都会造成“加入 FC4 后
看到 FC2 数值变化”。区别在于：Wick 收缩告诉我们如何把正交统计坐标还原成参考点导数；
污染则说明数据没有把不同 Taylor 贡献稳定地区分开。

## 如何判断观察到的是哪一种

1. 固定同一训练集和 `Sigma`，检查程序的精确恒等式
   `FC2_T = FC2_W - 1/2 FC4_W:Sigma + ...`。满足该式的差值是换基，不是污染。
2. 比较换基前后完整模型的逐快照力。数值容差内一致说明只是表示改变。
3. 改变训练样本、位移幅度和最高阶，观察最终 Taylor FC2、验证误差和设计条件性。超过
   统计误差的漂移才是截断或可辨识性风险。
4. 不要把 `FC2_W` 直接与有限差分 FC2、ALAMODE FC2 或 phonopy FC2 比较；这些外部量
   都是 Taylor 导数，应与 `FC2_T` 比较。
