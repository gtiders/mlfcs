# 长程静电路线

## 当前状态

规划短程拟合前的偶极长程力扣除，并记录所需 Born 有效电荷和介电张量输入。

## 计划边界

Roadmap 描述尚未成为稳定 API 的方向。页面中的公式、原型或研究结论不等同于已实现能力，用户工作流不得依赖它们。

## 进入实现的条件

需要先明确物理定义、数据需求、与 canonical IFC 的接口、失败语义和可验证基线，再以独立提交实现。不能为兼容实验代码增加永久双路径。

## 验收

实现必须有解析测试、结构与对称回归、真实材料案例和资源评估；若结果改变，应先区分 bug fix、ordering 变化和 regression。

## 非目标

不以扩大功能列表为目的，也不通过静默平均、投影或正则化掩盖不可辨识性。No-Go 结论会保留为设计依据。
