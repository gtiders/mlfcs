# 平移与周期标签

## 它是什么

区分 exact primitive translation $R$、有限超胞 cell label、HNF representative 和精确倒空间标签。

## 为什么重要

“平移与周期标签”决定数据在不同计算阶段中的物理身份。把结构标签、周期平移、数值数组或工作流对象混为一谈，会造成原子错配、重复计数或看似收敛但物理含义错误的结果。

## 与其他对象的关系

底层结构关系先定义原子和周期平移，interaction 与 orbit 在其上建立，参数化再把独立参数连接到 IFC。拟合、有限差分和物理工作流只能消费这些明确对象，不能自行猜测映射。

## 用户何时需要关心

准备 reference、设置 cutoff、解释参数数量、导出到目标超胞或排查结果差异时，都应核对本页概念。日常调用可以依赖公共 API，但跨软件转换时必须显式检查其语义。

## 检查原则

比较结果时优先比较结构标签、整数平移、张量和最终物理数组，不要只比较文件行序、内部编号或缓存顺序。
