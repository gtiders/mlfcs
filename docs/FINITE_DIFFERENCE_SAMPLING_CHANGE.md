# Finite-difference orbit and sampling changes for 4.0

[中文](FINITE_DIFFERENCE_SAMPLING_CHANGE_ZH.md)

MLFCS 4.0 changes how symmetry-reduced force-constant orbits are discovered and how independent
finite-difference observations are packed into displaced structures. This page records the
mathematical contract, the reason configuration counts can change, and the limits of the current
evidence. It is intentionally separate from the user-facing README.

## Two independent changes

### Complete canonical orbit discovery

Let `S` be the set of clusters that pass the physical periodic cutoff and let `canon(c)` be the
representative under space-group operations, tensor-axis permutations, and periodic anchoring.
The valid representative set is

```text
R = {canon(c) | c in S}.
```

An intermediate implementation instead retained only candidates satisfying
`c == canon(c)`. That is valid only when `S` is closed under canonicalization. Near periodic
boundaries, especially with degenerate images or skewed cells, a valid candidate can have a
canonical representative that the anchored candidate generator does not emit. Requiring equality
then deletes the entire physical orbit.

The implementation now canonicalizes every accepted candidate and deduplicates the resulting
representatives. This is a correctness repair, not a configuration-count optimization. In the
K4As4Pt2 maximum-MIC FC3 fixture, the defective implementation produced 4160 structures and only
122112 cluster images. The repair restores all 3387 orbits, 77730 independent parameters, and
136260 cluster images.

### Label-symmetric pivot and displacement-key compression

For one orbit, write the allowed tensor as

```text
phi_o = B_o theta_o,
```

where the columns of `B_o` span the null space of the orbit stabilizer constraints. MLFCS first
incorporates exchanges of tensor axes that carry the same atomic label, then selects independent
rows `P_o` such that

```text
rank(P_o B_o) = columns(B_o).
```

Consequently `P_o B_o` is invertible on the irreducible parameter space. Combining all orbits
gives a block observation map with rank equal to the total number of independent parameters.
This establishes algebraic recoverability; the basis, orbit support, and number of physical free
parameters are not reduced.

One displaced structure returns all `3N` Cartesian force components. For FC3, a fixed pair of
displaced degrees of freedom therefore observes every response component

```text
Phi[i,a,j,b,k,c] = -d^2 F[i,a] / (d u[j,b] d u[k,c]).
```

Several independent pivot rows can share the same displacement key while using different force
responses. Grouping those rows avoids recalculating the same structure. For K4As4Pt2 FC3, the old
selection used 1659 keys and the current selection uses 1061. The four-point central mixed
derivative therefore changes the plan from `1659 * 4 = 6636` to `1061 * 4 = 4244` structures,
while both correct implementations retain 77730 free parameters and the same 136260-cluster
support.

## What is proved, and what is not

Full rank proves that exact force observations uniquely determine the irreducible parameters:

```text
M theta_1 = M theta_2  =>  theta_1 = theta_2.
```

It does not prove optimal numerical conditioning. A remote or weak response may be comparable to
SCF, calculator, or cancellation noise. For an order-`n` force-derived central difference, force
noise is amplified approximately as `epsilon_F / h^(n-1)`. Both the previous and current
algorithms use force responses on atoms other than the displaced atoms and therefore share this
general finite-difference limitation. The current plan is closer to a minimum full-rank set and
should not be advertised as universally more noise resistant merely because it uses fewer
structures.

The K4As4Pt2 pypolymlp black-box comparison gives essentially the same FC3 numerical error as the
6636-structure plan, but this deterministic-potential result is not a substitute for noisy DFT
validation. Future robust sampling may add condition-aware pivot selection and optional redundant,
overdetermined observations with residual diagnostics.

## Scope of impact

The orbit repair affects both finite differences and fitting because both consume the shared
orbit space. It only changes a particular material and cutoff when the old candidate set was not
closed under canonicalization. The repository KAsPt settings (FC2 maximum range, FC3 12 bohr, FC4
8 bohr) were checked against an isolated defective implementation: orbit images, bases, pivots,
and parameter counts are identical. Those existing fits are not invalidated by this specific bug.

Because `sow()` ordering and configuration counts are part of an external force-calculation
workflow, users must not mix structures generated by an earlier plan with forces reaped by 4.0.
Regenerate the complete ordered structure list whenever upgrading across this change.
