# MLFCS 新旧实现差异

[English](OLD_NEW_COMPARISON.md) | 中文

本文对比旧版 MLFCS 与当前 MLFCS 3.0 的设计、算法、输出和已验证行为。
“兼容”不表示逐行复制旧代码，而是区分以下三类目标：

1. 必须一致：结构、近邻截断、有效不可约团簇、位移任务、原子顺序和文件块顺序；
2. 物理上应改正：旧版四阶 ASR 的双原子轴求和及相对权重补偿；
3. 新增能力：二阶、任意高阶稀疏表示、JAX 后端、HDF5 和可选 SSCHA。

## 总览

| 项目 | 旧版 | 新版 v3.0 |
|---|---|---|
| 公共接口 | 三阶、四阶各自的 CLI/API | 统一纯 Python API |
| 计算器 | 工作流中集成或适配 | 用户提供 ASE Calculator 或外部力 |
| 阶数 | 三阶和四阶分开实现 | 同一参数化算法支持 `order>=2` |
| 超胞顺序 | 依赖生成和文件约定 | 显式、确定性的 cell-major 顺序 |
| 周期原子身份 | 位置和隐式编号 | `primitive_index + cell_translation` |
| 团簇轨道 | 三、四阶重复实现 | 通用 `OrbitSpace` 和张量秩 |
| 有限差分 | 固定阶数公式 | 递归中心差分模板 |
| 对称变换 | 容易物化大型矩阵 | JAX 张量旋转和轴置换 |
| 重建结果 | 以阶数特定稠密结构为主 | 稀疏团簇图像，按需物化 |
| ASR | 相对权重补偿；四阶双轴求和 | 单轴严格受约束投影 |
| 大约束求解 | 可能使用大型稠密 SVD | 小 Gram 零空间与稀疏 LSMR |
| 输出 | 阶数和 CLI 耦合 | 显式 `format=` 路由 |
| 高阶输出 | 无统一格式 | 任意阶稀疏 HDF5 |
| phonopy FC2 | 依赖相关接口 | 基础 writer 无 phonopy 依赖 |
| 有限温度 FC2 | 旧 `MLPSSCHA` 封装 | 独立可选 `mlfcs.sscha` 模块 |

## 1. API 和职责边界

### 旧版

旧版分别维护 thirdorder 和 fourthorder 工作流。读取结构、生成超胞、计算对称性、
写出位移结构、读取力和输出力常数等行为分散在阶数特定代码中。

这带来几个问题：

- 三阶和四阶的修复容易不同步；
- 文件命名和 CLI 约定参与核心计算；
- Calculator、文件接口和重建逻辑耦合；
- 要增加五阶时，需要复制并修改大量代码。

### 新版

新版统一使用：

```python
calculation = ForceConstantCalculation(
    atoms,
    order=3,
    supercell=(2, 2, 2),
    cutoff=-5,
)

structures = calculation.sow()
force_constants = calculation.reap(forces)
```

MLFCS 只规定结构和力的数据契约，不规定力从哪里获得。用户可以：

- 把 `sow()` 结构提交到外部集群；
- 使用任意程序计算力；
- 按 ID 字典乱序回收；
- 或把 ASE Calculator 传给 `run()` 串行执行。

新版没有 CLI，也不内置 calorine、NEP 或其他具体势函数依赖。

## 2. 超胞和原子顺序

### 旧版风险

旧版的顺序由超胞生成循环、结构文件和不同接口共同决定。只要力数组与写出结构的
原子顺序不一致，即使张量分量全部正确，最终力常数也会错误。

这种错误往往很隐蔽，因为：

- 元素相同的原子交换后结构看起来没有变化；
- 总能量可能保持一致；
- 只有逐原子力和输出块映射出现偏差。

### 新版约定

新版内部顺序固定为：

```text
z → y → x → primitive_atom
```

原胞原子变化最快。超胞显式保存：

```text
primitive_index
cell_translation
primitive_scaled_position
```

`sow()` 和位置式 `reap()` 使用完全相同的顺序。每个构型还保存：

```text
mlfcs_configuration_id
mlfcs_atom_order
mlfcs_displacement
```

phonopy 所用的 primitive-atom-grouped 顺序仅在格式边界转换，不改变内部计算顺序。

## 3. 负近邻壳层

### 用户壳层半径

旧版 `calc_frange` 对每个原胞原子构造唯一距离列表，其中包括自身距离 0。第 `n`
近邻的截断为：

```text
0.5 × (u[n] + u[n+1])
```

新版先删除自身距离 0，再使用：

```text
0.5 × (unique[n-1] + unique[n])
```

两种索引方式等价。对于多原子材料，两版都取全部原胞原子结果的最大值，保证每种
原子中心都包含到指定壳层。

旧版使用 nm；新版统一为 Å，因此同一物理半径的数值相差 10 倍。

### 超胞上限

旧版在超胞不足时发出警告，再使用最远距离的 `1.1` 倍兜底。这可能让用户指定的
“第 n 近邻”实际退化成“当前超胞最远可见距离”。

新版额外计算所有原胞原子共同支持的 MIC 距离壳层上限。超过上限时直接报错，并
打印两个不同概念：

```text
Supercell neighbor limit: maximum shell = 33, maximum cutoff radius = 15.7504983443 Å
Selected neighbor cutoff: shell = 8, cutoff radius = 7.5419604204 Å
```

第一行是超胞容量，第二行才是本次真正使用的截断。

## 4. 周期像和团簇截断

这是新旧对齐过程中最重要的一处修复。

### 旧版逻辑

旧版先固定一个原胞锚点。对每个尾原子，在 27 个相邻超胞平移中保留所有与锚点
距离最小的周期像。两个尾原子只有在它们各自的锚点最小像中，至少存在一对彼此也
位于截断范围内时才兼容。

旧版最小像简并判断使用：

```text
|d² - d²_min| < 1e-4 nm²
```

等价于新版的：

```text
1e-2 Å²
```

### 新版曾经的差异

早期新版曾对团簇的每一条边分别使用 ASE MIC。每条边各自都可以很短，但这些最短
周期像未必能够在同一个锚点表示中同时成立，于是会纳入不存在一致周期几何的
“拼接三角形”。

K3Au3Sb2、三阶、`3×3×3/-8` 中，这曾多产生 14 个轨道，并增加一个位移键和四个
力构型。

### 当前新版

当前实现已经恢复旧版锚点最小像兼容逻辑，并将其参数化到任意阶。K3Au3Sb2
三阶 `3×3×3/-8` 当前得到：

| 指标 | 旧版 | 新版 |
|---|---:|---:|
| 旧版报告的类别 | 253 | — |
| 零维 onsite 类 | 2 | 默认排除 |
| 有效轨道 | 251 | 251 |
| 独立参数 | 4711 | 4711 |
| 位移任务 | 272 | 272 |
| 力计算构型 | 1088 | 1088 |

因此剩余的 `253` 与 `251` 差别不是周期像错误，而是新版不保留两个零维 onsite
对称子空间。

## 5. 不可约团簇和对称性

### 旧版

三阶和四阶分别实现：

- 团簇枚举；
- 空间群映射；
- 原子指标置换；
- 笛卡尔张量约束；
- 不可约分量选择。

这种结构容易使不同阶数采用稍有差异的容差或约束逻辑。

### 新版

新版使用统一的 `OrbitSpace`：

```text
ClusterOrbit
  representative
  invariant tensor basis
  pivot components
  symmetry-generated images
```

阶数只决定：

- 团簇包含多少原子指标；
- 张量具有多少个笛卡尔轴；
- 需要多少个轴置换；
- 稳定子约束矩阵的大小。

对称操作保存为“笛卡尔旋转 + 张量轴置换”，而不是在关键路径长期保存完整的
`3**order × 3**order` 矩阵。

需要区分两类“对称性”：

- 交换完整的 `(原子指标, 笛卡尔指标)` 对属于正确的力常数置换对称性；
- 在 ASR 中同时对两个原子指标求和不是置换对称性，而是旧版四阶的错误约束。

## 6. 有限差分和位移任务

### 旧版

三阶与四阶分别编码位移组合和符号。增加新阶数需要重新实现对应公式。

### 新版

`n` 阶力常数来自力的 `n-1` 次导数。新版递归生成中心差分符号：

```text
名义符号组合数量 = 2**(order-1)
```

随后按对称性和实际位移键去重。所有写出构型均有稳定 ID，`reap()` 可以按 ID
验证构型是否完整，或直接按严格写出顺序回收。

这使二阶至五阶使用相同的数据流，而不是为每阶复制公式。

## 7. 重建表示和内存

### 旧版

旧版阶数特定路径更倾向于构造较大的中间数组和稠密张量。四阶或更高阶时，数组
尺寸会非常快地增长。

### 新版

新版重建结果保留为：

```text
clusters: (number_of_images, order)
tensors:  (number_of_images, 3, ..., 3)
```

只有用户请求 `materialize()` 或某种稠密输出时才构造完整数组。超过默认内存预算
会发出警告，但不会擅自终止；任意高阶 HDF5 不需要稠密化。

已测量案例：

| 案例 | 旧版峰值内存 | 新版峰值内存 |
|---|---:|---:|
| Si 四阶路径 | 约 9.51 GiB | 约 1.08 GiB |
| NaS 四阶 | 约 4.92 GiB | 约 1.14 GiB |

NaS 五阶、`2×2×2/-1` 的稀疏结果：

- 16 个不可约轨道；
- 403 个独立参数；
- 2432 个力构型；
- 1686 个稀疏团簇图像；
- HDF5 约 789 KiB；
- 等价稠密张量约 243 GiB。

这说明高阶支持必须建立在稀疏表示上，不能仅仅把阶数变量改成 5。

## 8. ASR 的物理差异

### 正确约束

对 `n` 阶力常数，固定其他所有指标，只对一个原子指标求和：

```text
Σ_in Φ(i1, ..., in) = 0
```

置换对称性会产生其他原子轴上的等价约束。

### 旧版三阶

旧版三阶对一个原子轴求和，约束形式接近正确 ASR，但使用基于力常数相对大小的
补偿。它不是严格的最小距离受约束投影，可能把残差集中到较大分量。

在保存的 Si 数据中：

- 原始最大分量约 `8.71`；
- 旧版补偿后最大分量约 `34.30`；
- 新版严格投影后约 `8.37`。

### 旧版四阶

旧版四阶同时对两个原子轴求和，近似约束为：

```text
Σ_k,l Φ(i,j,k,l) = 0
```

正确要求则是对每个固定的 `k` 分别满足：

```text
Σ_l Φ(i,j,k,l) = 0
```

双重总和允许不同 `k` 切片的错误互相抵消，因此明显更弱，会放过不满足平移
不变性的 FC4。

### 新版

新版在不可约轨道参数空间构造稀疏约束矩阵 `A`，严格求解：

```text
min ||p - p_measured||²
subject to A p = 0
```

小参数空间使用 `A.T @ A` 的零空间，再用原始稀疏 `A` 中的 LSMR 精修；大参数
空间直接使用稀疏 LSMR。

因此，新版不把旧版 ASR 后的数值作为兼容目标。新版兼容的是 ASR 之前的几何、
团簇、位移、重建和输出顺序。

已测 Si 残差：

- 三阶最大 ASR 残差：`3.89e-15`；
- 四阶最大 ASR 残差：`2.54e-14`。

严格四阶与旧版四阶的差异为：

- 最大绝对差：`1.31e-3`；
- RMS：`5.71e-5`。

这里的差值是新旧最终力常数之间的差值，不是算法内部残差。

## 9. 输出格式与顺序

### 旧版

writer 与 thirdorder/fourthorder 工作流耦合，格式选择和文件写出通常由 CLI 控制。

### 新版

统一使用：

```python
force_constants.write(path, format=..., order=...)
```

当前支持：

| 格式 | 阶数 | 表示 |
|---|---|---|
| MLFCS HDF5 | 任意阶 | 稀疏团簇或稠密数组 |
| NumPy/NPZ | 任意阶 | 物化数组 |
| ShengBTE | 三阶、四阶 | 团簇块和晶格平移 |
| phonopy | 二阶 | 完整稠密超胞 FC2 |

ShengBTE 三阶和四阶统一使用科学计数法。writer 从内部原胞编号和晶格平移推导
目标块，而不是假设一个全局稠密数组顺序。

phonopy FC2 writer 会：

1. 把紧凑 FC2 展开为完整 `(N,N,3,3)`；
2. 利用平移等价填充第一个超胞原子轴；
3. 将两个原子轴转换为 phonopy grouped 顺序；
4. 写出 phonopy 官方文本布局。

该 writer 本身不依赖 phonopy，但输出已经由 phonopy 官方解析器验证。

## 10. 二阶和任意高阶

旧版主要针对三阶和四阶。新版 `order` 参数贯穿：

- 团簇枚举；
- 轨道构造；
- 张量对称性；
- 位移模板；
- 重建；
- ASR；
- HDF5。

二阶可以使用相同 API 计算，并导出 phonopy `FORCE_CONSTANTS`。五阶已经完成复杂
材料第一近邻端到端测试。六阶及以上在原理上相同，但尚未作为生产规模路径验证。

ShengBTE 只有三阶和四阶 writer，不限制内部计算阶数；更高阶使用 HDF5。

## 11. SSCHA 接口差异

### 旧版 `MLPSSCHA`

旧版在 phonopy `MLPSSCHA` 思路上增加 ASE 适配、末轮平均和自动文件写出：

- 构造对象时即计算未位移超胞能量；
- 通过 phonopy MLP adapter 调用 ASE Calculator；
- `run()` 内部打印自由能历史；
- 可在运行结束时自动平均并写文件；
- 外部逐轮作业接口不完整；
- 随机种子没有完整暴露。

### 新版 `mlfcs.sscha.SSCHA`

新版以原生 q 空间采样和 MLFCS Gram FC2 拟合器替换 phonopy/symfc 后端：

- 构造阶段不调用势函数；
- 直接接受用户的 ASE Calculator；
- 支持逐轮 `sow/reap` 外部调度；
- 显式 `random_seed`；
- 每轮返回不可变 `SSCHAIteration`；
- 保存 FC2、自由能、标准误差和能量均值历史；
- 平均和写出由用户显式调用，不产生隐式文件副作用；
- 记录 q 点、有效模态、虚频、低频排除和可选位移裁剪诊断。

两版都采用随机热位移重新拟合有效 FC2，而不是显式计算 FC3 bubble 或 FC4 loop。

## 12. 兼容性边界

### 应当与旧版一致

- 相同结构和超胞的原子身份；
- 负近邻壳层解析半径；
- anchor-minimum-image 团簇兼容性；
- 排除零维张量空间后的有效不可约轨道；
- 独立参数数量；
- 位移任务和力构型数量；
- `sow/reap` 力与原子的对应关系；
- ShengBTE 块、原子、平移和笛卡尔分量顺序。

### 有意不与旧版一致

- 三阶相对权重 ASR 补偿；
- 四阶双原子轴求和；
- 超胞不足时静默或警告后兜底；
- CLI 和隐式文件命名；
- nm 内部单位；
- 高阶稠密优先的数据流。

### 新增而旧版没有统一提供

- 二阶同一计算 API；
- 任意阶参数化流程；
- 稀疏任意阶 HDF5；
- 明确的构型 ID；
- JAX CPU/GPU 选择；
- 内存估算警告；
- phonopy 完整 FC2 writer；
- 原生 q 空间 SSCHA 模块。

## 13. 当前建议

后续演进应继续遵守以下原则：

1. 旧版用于黑盒验证几何、任务计划和格式顺序，而不是复制其错误 ASR；
2. 所有新格式通过统一的晶格地址和稀疏力常数视图实现；
3. 不为了兼容二、三阶格式而强制高阶结果稠密化；
4. 对任何新周期像算法使用多组分复杂材料回归，不能只测试 Si；
5. 大型测试始终串行运行并监测峰值内存；
6. Calculator 保持用户所有，核心包不绑定具体势函数。

更完整的架构和数值细节见[技术总览](TECHNICAL_OVERVIEW.md)，SSCHA 使用方式见
[SSCHA 文档](SSCHA_ZH.md)。
