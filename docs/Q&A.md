# Q&A

这里收集使用时容易遇到的判断与误区。完整的参数说明和代码示例见各 API 章节。

## 为什么增加训练结构以后，仍然无法区分某些参数？

先检查超胞本身是否足够大、形状是否合适。不同晶格相互作用折叠到同一个超胞原子组合后，可能只留下它们的总和；再多训练结构也无法拆开这个总和。

可以在计算力之前调用 `mapping.rank_info(order).require_full()` 检查结构可辨识性。如果这里通过，而拟合仍然缺少参数方向，再检查位移样本是否充分激发了这些方向。两种情况分别需要改变超胞和补充采样，不能都靠增加帧数解决。见[核心概念](core-concepts.md)和[拟合](fitting-api.md)。

## 有限差分计算中途停止，怎样接着做？

保留原始结构及其序号，补算缺失的帧，最后按 `fd.sow()` 的顺序收集全部结果。也可以用相同的参考结构、模型设置、mapping 和步长重新生成采样序列。

`reap()` 不会根据位移自动排序。即使数量正确，错误的帧顺序也可能产生错误力常数而不报错；外部计算按完成时间返回结果时尤其要检查。见[有限差分](finite-difference-api.md)。

## 力必须由某一种 calculator 计算吗？

不需要。可以使用适用的 ASE calculator，也可以在外部电子结构程序中计算，再将结果保存到对应的 ASE 结构中。`ForceDataset` 读取已经保存的力，不会替用户启动计算。

无论力从哪里来，都要保持参考超胞的原子顺序，并使用 Å 和 eV/Å 作为位置与力的单位。数据准备见[核心概念](core-concepts.md)。

## 极性材料拟合高阶力常数前，要先扣除长程力吗？

当 Born 有效电荷与电子介电张量已知，且偶极模型适用时，建议先扣除长程谐波力，再拟合短程 FC2、FC3、FC4。否则有限 cutoff 的模型可能把未描述的长程贡献吸收到短程参数中，影响高阶参数的可靠性。

这并不保证所有体系的误差都会下降，仍需检查验证集和截断收敛。扣除后得到的是短程模型；需要总 FC2 时，要回加同一份长程贡献。当前 Ewald 模型只提供长程 FC2，不包含非线性长程力。见[长程力与 Ewald](ewald-api.md)。

## 开启 ASR 后，为什么仍可能出现虚频？

ASR 约束刚性平移，不要求所有模式的曲率为正。虚频可能来自结构的不稳定性，也可能来自数据误差、截断或尚未收敛的模型。不能仅凭 ASR 残差小就判断动力学稳定。

ASR 在 `ClusterSpace(..., asr=True)` 中开启：拟合直接使用受约束坐标，有限差分先重建物理参数再投影。旋转不变性是另一组条件，需要显式调用 `ForceConstants.enforce_rotation()`；它不能代替 ASR。见[平移与旋转不变性](theory/invariance-constraints.md)。

## 原生文件加载后，还能继续使用 ASR 坐标吗？

`ForceConstants.save()` 和 `load()` 保存、恢复力常数模型，但加载不会重新构造自由声学坐标。已有系数可以保持保存前的 ASR 性质，这不等于加载后的对象已经具备后续约束求解所需的坐标映射。

需要在 SCPH 等计算中继续使用 ASR 时，应以一致的参考结构和模型设置重新建立 `ClusterSpace(..., asr=True)`，并核对参数布局后绑定系数。具体步骤见[SCPH](scph.md)。

## 正规方程更省内存，为什么结果可能与直接最小二乘不同？

正规方程保存参数规模的矩阵，避免保留全部力方程；但满列秩时，形成 $A^TA$ 会把二范数条件数平方。原本难以区分的参数方向因此更容易损失精度。直接路线与正规路线在精确算术下对应相同目标，浮点结果不必完全一致。

列缩放有助于平衡量级，不能补回缺失的观测信息。选择路线时应同时比较内存、验证误差和求解是否收敛。见[拟合](fitting-api.md)。
