# 路线图

[English](ROADMAP.md) | 中文

当前开发暂时停留在现有 `dev` 实现。继续增加功能之前，下一个里程碑将集中处理以下
两项相互关联的工作：

1. **完整的物理真实性测试。** 建立可复现的验证矩阵，覆盖留出集力预测、对称性与
   求和规则残差、逐阶稳定性、声子物理量以及完成收敛测试的热输运计算。与独立实现
   比较时，将严格统一超胞、相互作用支撑域、作用体数、约定和数值参数。仅凭两份拟合
   力常数文件彼此接近，不视为物理真值证明。
2. **高阶不可约集合的可扩展性。** 定位并消除不可约簇枚举的组合爆炸；该问题目前使
   六阶计算难以实际运行。后续将研究更早的对称性剪枝、规范代表的增量构造、有界的
   中间存储和可复现的规模测试，同时保证已经建立的 FC2--FC4 结果不发生非预期变化。
3. **高阶稀疏约束拟合。** 当前投影 Gram 求解器已经流式构建设计矩阵，但零空间投影仍
   会形成稠密 `C @ C.T`。后续将增加自动内存估算，并在大约束系统上替换为经过验证的
   稀疏受约束方法，例如稀疏 KKT/MINRES 或增广拉格朗日方案。算法选择由程序自动完成，
   同时必须保持严格的 ASR 和旋转约束残差。
4. **周期几何压力测试。** 通用 MIC 与约化晶格简并镜像处理已经成为计算核心。后续扩展
   强倾斜晶胞、边界简并和更多外部读取器的验证矩阵；ALAMODE 固定 27 镜像编码仍是
   格式层限制，无法表示时必须继续拒绝导出。
5. **拟合时冻结已有阶次的 IFC。** 允许使用 native HDF5 v2 结果提供固定的低阶 Taylor
   IFC，只拟合其余连续阶次；初始 API 采用构造期声明，例如
   `fixed={2: read_hdf5("fc2.h5")}`。实现必须是严格的仿射约束拟合，不能在拟合结束后覆盖
   结果：Wick 基拟合中 FC4 会收缩到 Taylor FC2，旋转恒等式也会耦合相邻阶次。因此需要
   组装 `E p = b`，求得 `p = p0 + Z q`，从训练力中扣除固定贡献 `A p0`，然后只求解自由
   坐标 `q`。拟合前必须严格验证 primitive/reference 等价性、lattice-labelled 支撑域、
   cutoff/作用体数兼容性、轨道 pivot 重建，以及所请求 ASR 和旋转约束是否存在可行解；
   禁止静默投影用户提供的固定 IFC。最终在一个物理 `ForceConstants` 结果中同时返回固定
   与拟合阶次，记录来源，并把固定张量及仿射映射纳入持久 Gram 缓存指纹。第一版在冻结
   阶次时应拒绝 scaled group LASSO，直到仿射坐标中的物理轨道分组正则化得到明确定义。

除上述已经明确设计的项目外，其余项目仍可调整实现方案。所有后续改动只有在配套专项
测试和数值证据后才会引入。
