# 路线图

[English](ROADMAP.md) | 中文

当前开发暂时停留在现有 `dev` 实现。继续增加功能之前，下一个里程碑将集中处理以下
两项相互关联的工作：

1. **完整的物理真实性测试。** 建立可复现的验证矩阵，覆盖留出集力预测、对称性与
   求和规则残差、逐阶稳定性、声子物理量以及完成收敛测试的热输运计算。与独立实现
   比较时，将严格统一超胞、相互作用支撑域、作用体数、约定和数值参数。仅凭两份拟合
   力常数文件彼此接近，不视为物理真值证明。
2. **高阶正则/阻尼约束拟合。** 默认无正则 `damping=0` 路径已经使用分块稀疏零空间，
   但 scaled group LASSO 和非零 damping 的隐式投影仍会形成稠密 `C @ C.T`。后续将增加
   自动内存估算，并在大约束系统上替换为经过验证的稀疏受约束方法，例如稀疏 KKT/MINRES
   或增广拉格朗日方案。算法选择由程序自动完成，同时必须保持严格的 ASR 和旋转约束残差。
3. **旋转约束条件数缺陷。** 当前 FC1–FC2 硬边界使用与结构容差相关的数值秩过滤，
   而 hiphive 使用岭正则软投影；二者语义不同，接近零的奇异方向可能随单位和缩放被
   错误保留为硬约束或被丢弃。后续应改为显式无量纲条件判据，并提供独立的 Huang/
   Born–Huang 软投影。FC2、FC3 和 FC4 都必须通过 materialize 后的物理恒等式验证，
   并覆盖平面 graphene 与 MoS2 案例。

除上述已经明确设计的项目外，其余项目仍可调整实现方案。所有后续改动只有在配套专项
测试和数值证据后才会引入。
