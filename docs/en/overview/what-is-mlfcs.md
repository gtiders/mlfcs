# What is MLFCS?

MLFCS is an ASE-first library that constructs symmetry-reduced harmonic and anharmonic force constants from atomic forces. It focuses on force-constant construction, fitting, constraints, realization, and export rather than replacing downstream phonon or transport solvers.
