# What is MLFCS?

## Scope

This page places “What is MLFCS?” in the complete MLFCS workflow: what it solves, what it connects, and what remains outside its scope. MLFCS is an ASE-first library that constructs symmetry-reduced harmonic and anharmonic force constants from atomic forces. It focuses on force-constant construction, fitting, constraints, realization, and export rather than replacing downstream phonon or transport solvers.

## How to use this page

Fix the input structures, units, and downstream application first, then continue to Concepts, Tutorials, or How-to. Executable signatures belong to Reference.

## Boundaries and validation

Stable capabilities must be reproducible with the current public API and repository cases. Planned and research material is not an implemented feature.
