# Why MLFCS?

## Scope

This page places “Why MLFCS?” in the complete MLFCS workflow: what it solves, what it connects, and what remains outside its scope. High-order force constants face combinatorial cluster growth, tensor symmetry, memory pressure, and coupled errors between Taylor orders. MLFCS provides one sparse, symmetry-aware representation shared by finite differences, fitting, constraints, and export.

## How to use this page

Fix the input structures, units, and downstream application first, then continue to Concepts, Tutorials, or How-to. Executable signatures belong to Reference.

## Boundaries and validation

Stable capabilities must be reproducible with the current public API and repository cases. Planned and research material is not an implemented feature.
