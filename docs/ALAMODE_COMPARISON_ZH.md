# MLFCS 拟合后端与 ALAMODE 的算法和架构比较

本文比较的是 MLFCS 的 `mlfcs.fitting` 仅力数据拟合后端与 ALAMODE 的 IFC 优化功能，
而不是比较两个项目的全部能力。ALAMODE 还包含完整的声子、非谐声子、热输运和 SCPH
后处理体系；MLFCS 则同时提供有限差分 `sow()` / `reap()` 路径和通用力常数 I/O。

比较依据为本仓库所附 ALAMODE 源码及其 `formalism_alm.rst`、`inputalm.rst` 文档。
除非给出实际测试结果，本文不宣称任何一方在绝对运行速度或内存占用上必然更优。

## 共同的数学问题

两者最终都求解关于不可约力常数参数的线性力模型：

```text
F = A Φ
```

`Φ` 包含经过晶体对称性、指标置换和约束约化后的 FC2、FC3 等参数，设计矩阵 `A`
由训练结构的位移及其高次乘积构造。两者均可仅根据结构和原子力拟合，不要求能量。

因此，MLFCS 并不是用神经网络替代 ALAMODE 的线性回归，而是采用不同的数据表示、
设计矩阵执行方式、数值求解器和 Python 集成边界求解同类问题。

## 核心差异

| 方面 | MLFCS 当前拟合后端 | ALAMODE `alm` |
|---|---|---|
| 公共接口 | 纯 Python API；直接接收 ASE `Atoms` | 输入文件与 DFSET 工作流为主 |
| 当前拟合阶数 | 连续阶联合拟合；FC2--FC4 已端到端测试 | 成熟支持二阶到高阶 |
| 力模型 | 线性 IFC 模型 | 线性 Taylor expansion potential |
| 高阶基 | 协方差正交化的 Wick 特征 | 普通位移幂 Taylor 特征 |
| 设计矩阵 | 矩阵无关或流式累积 `AᵀA`，不保留完整矩阵 | 稠密矩阵或显式稀疏矩阵 |
| 求解器 | LSMR；流式 Gram 与隐式约束零空间 | OLS；稠密 SVD/QR 或 Eigen 稀疏求解器 |
| 特征尺度 | 每个不可约参数的列范数预条件 | elastic net 可逐列标准化；也可统一缩放位移 |
| 正则化 | 当前为无阻尼或可选 LSMR damping | OLS、elastic net、adaptive LASSO |
| 超参数选择 | 尚无自动正则化选择 | elastic net 支持自动/手动交叉验证扫描 |
| 约束 | 通过隐式零空间把平移/旋转关系嵌入拟合 | 可把平移/旋转不变性纳入不可约参数关系 |
| 加速路径 | JAX JIT、批处理、CPU/GPU 可选 | C++、Eigen、MPI 及稀疏线性代数 |
| 输出生态 | `ForceConstants`、phonopy、ShengBTE、HDF5、NumPy | ALAMODE XML/文本及其完整后处理生态 |

## MLFCS 的主要优势

### 1. 设计矩阵不占驻留内存

MLFCS 把 `A` 表示成线性算子。LSMR 每次只请求：

```text
x -> A·x
r -> Aᵀ·r
```

两个操作都按 `batch_size` 分批处理训练结构。增加训练构型数主要增加算子遍历时间，
不会要求把完整 `N_force × N_parameter` 矩阵同时放进内存。这对随机位移、AIMD 快照和
高阶参数较多的场景尤其有价值。

ALAMODE 也提供稀疏矩阵求解器，在只有少数原子被移动时很有效；但随机热快照通常使
设计矩阵接近稠密，此时显式稀疏存储的优势可能下降。最终优劣仍需在相同数据集、相同
阶数和截断下测量。

### 2. 批次只控制资源，不改变最小二乘目标

MLFCS 的批次不是随机梯度小批次。每一次 LSMR 迭代仍累计全部训练数据的精确 `A·x`
和 `Aᵀ·r`，所以更改 `batch_size` 理论上只改变峰值内存和吞吐，不应改变收敛解。

### 3. FC2 与 FC3 的逐参数尺度处理

不同阶的力特征典型尺度分别为 `u`、`u²`、`u³`。MLFCS 用随机迹估计获得每一个设计
矩阵列的范数，并求解经过预条件的系统。这样无需为每阶人工设置学习率，也避免此前
Adam 中 FC3 因小位移而几乎不更新的问题。

ALAMODE 的 elastic net 同样提供逐列均值/标准差标准化，这是成熟而有效的类似思路；
其 OLS 模式是否需要标准化取决于所选直接或迭代求解器。MLFCS 的区别是把列尺度处理
作为矩阵无关 LSMR 的默认数值预条件，而不是仅服务于 L1/L2 正则化。

### 4. Wick 基缓解相邻阶吸收

MLFCS 可用训练位移协方差构造：

```text
H2 = uu - C
H3 = uuu - C·u - C·u - C·u
```

它使不同次数的特征在理想高斯分布下正交，在一般分布下也通常能降低相关性，从而缓解
FC2 吸收 FC4、FC3 吸收 FC5 等有限阶截断污染。该性质是统计意义上的解耦，不保证有限
样本或非高斯采样下完全正交，也不替代加入物理上必要的更高阶。

完成拟合后，程序会在 `ForceConstants` 边界把完整 Wick 系数层级精确换基为普通
Taylor 力常数。`FC2_T = FC2_W - 1/2 FC4_W:Sigma` 等同奇偶阶收缩只是代数坐标变换，
不是第二次回归，也不会让低阶重新吸收高阶贡献。

ALAMODE 使用标准 Taylor 位移幂，因此所得系数直接对应选定参考结构的 Taylor 参数；
高阶污染通常通过扩大拟合阶数、正则化和交叉验证处理。两种基的物理解释并不完全相同。

### 5. ASE/JAX 和结果对象集成

MLFCS 直接接受 ASE 结构及任意来源的 forces，结果进入统一 `ForceConstants` 数据模型，
可继续施加 ASR、比较稀疏支撑域并导出 phonopy、ShengBTE 或 HDF5。JAX 后端允许同一
算子选择 CPU 或 GPU，并能组合 `jit`、批处理和自动转置算子。

## MLFCS 当前的不足

### 1. 高阶拟合成熟度明显不及 ALAMODE

当前 FC4 已完成端到端拟合测试，但其验证广度仍明显少于 ALAMODE。ALAMODE 已长期使用
elastic net 和 adaptive LASSO 处理四阶及更高阶问题，并配有教程和实际材料工作流。

### 2. 缺少成熟的稀疏正则化和自动模型选择

MLFCS 目前只有无阻尼 LSMR 和数值 damping 接口，尚未提供：

- elastic net；
- adaptive LASSO；
- 正则路径；
- k 折交叉验证；
- 自动选择正则强度；
- 去偏 OLS。

在高阶参数数目超过独立力方程数，或训练数据噪声较大时，这些能力非常重要。LSMR 的
提前停止只能提供有限的隐式正则化，不能替代完整的模型选择。

### 3. 矩阵无关后端的列范数仍是随机估计

Hutchinson 探针避免显式构造矩阵，但列范数带有抽样误差。探针太少可能造成不同运行
之间的轻微差别，探针太多则增加 `Aᵀ·r` 成本。ALAMODE 对显式矩阵可计算精确列统计量。
流式 Gram 后端已经提供确定性的精确列范数；随机探针仅保留在矩阵无关 LSMR 路径。

### 4. 每次 LSMR 迭代的算子成本较高

矩阵无关减少存储，但 LSMR 每一轮都需要遍历训练数据并执行一次或多次 JAX 算子。
对于能够放入内存的小问题，ALAMODE 的一次性稠密矩阵构造加 SVD/QR 可能更快，并能
提供更直接的秩诊断。MLFCS 不应默认声称矩阵无关方法在所有规模上更快。

### 5. 约束验证广度仍有限

当前 MLFCS 使用 `C Cᵀ` 的秩揭示伪逆构造隐式零空间投影，并在该空间内求解 Gram
最小二乘；冗余约束不会再导致 KKT 不收敛。不过 ALAMODE 的平移与旋转约束具有更长的
生产验证历史，MLFCS 仍需扩充材料与高阶约束基准。

### 6. 生态范围更窄

ALAMODE 提供从 IFC 拟合到非谐声子、热导率、SCPH 和结构弛豫的一体化工具。MLFCS 的
优势在于 ASE-first 计算和跨格式输出，但不试图替代 ALAMODE 的全部后处理能力。

## 已有数值证据

在仓库中的 KAsPt、`2×2×3` 超胞、150 个随机位移结构、FC2 无截断、FC3 截断
12 bohr 的测试中，MLFCS 矩阵无关系统包含 48,600 个力方程和 5,053 个不可约参数：

```text
LSMR iterations                  32
training relative force error   4.623205 %
validation relative force error 5.080075 %
training force RMSE              0.00664101 eV/Å
validation force RMSE            0.00704161 eV/Å
peak resident memory             approximately 2.78 GiB
```

与同一势函数的零步长有限差分外推结果相比：

| 阶数 | 相对 L2 差异 | 余弦相似度 |
|---|---:|---:|
| FC2 | 2.443% | 0.999706 |
| FC3 | 4.291% | 0.999084 |

该结果证明当前实现能够在这个测试上恢复与局部有限差分一致的 FC2/FC3。它不是与
ALAMODE 的速度或内存基准，不能据此推导跨软件性能结论。

同一材料使用全部 250 个快照，并联合拟合 FC2+FC3+FC4（FC2 最大范围、FC3 为 12
bohr、FC4 为 8 bohr）时，共有 90,000 个力方程和 7,756 个不可约参数。流式 Gram CPU
后端用 590.00 秒构建充分统计量，在 1,405 轮投影 CG 后收敛；完整运行耗时 719.81 秒，
峰值 RSS 约 4.87 GiB，相对力误差为 5.954683%，联合 ASR 残差为 4.07e-15。该数据仅是
MLFCS 的实现基准，不是与 ALAMODE 的性能对比。

该 FC2--FC4 拟合执行 Wick→Taylor 换基后，FC2 相对变化 3.274%，FC3 和 FC4 数值不变。
按周期锚点和张量排列规范化后，与所给 ALAMODE 文件相比，FC3 相对 L2 差异为 7.413%，
余弦相似度为 0.997350；共同支撑上的 FC4 相对 L2 差异为 52.015%，MLFCS 另有 54 个
规范 FC4 簇。这些是数值诊断，不代表软件性能排名。

## 适用场景建议

优先考虑 MLFCS：

- 数据已经是 ASE `Atoms`；
- 需要把随机结构、机器学习势和 IFC 导出组合进 Python 工作流；
- 显式设计矩阵可能超过可用内存；
- 当前目标是联合 FC2--FCn，并希望使用 Wick 基缓解阶间相关；
- 需要直接输出 phonopy、ShengBTE 或 MLFCS 稀疏 HDF5。

优先考虑 ALAMODE：

- 需要成熟的 FC4 及更高阶稀疏拟合；
- 需要 elastic net、adaptive LASSO 和系统交叉验证；
- 需要把旋转/平移约束严格纳入拟合；
- 需要 ALAMODE 的 SCPH、非谐声子和热输运生态；
- 问题规模适合显式矩阵和成熟直接求解器。

二者也可以互补：MLFCS 负责 ASE 数据接入、矩阵无关拟合和通用导出，ALAMODE 用于
独立数值验证或后处理。比较结果时必须固定参考结构、原子顺序、单位、截断、周期镜像
支撑域、约束设置和训练/验证划分。
