# JOSS paper sources

English | [中文](README_ZH.md)

[`paper.md`](paper.md) and [`paper.bib`](paper.bib) are the English submission sources for the
Journal of Open Source Software. [`paper_ZH.md`](paper_ZH.md) is a Chinese reading copy maintained
for project users; it is not passed to the JOSS build. Numerical claims in both versions should be read alongside the archived validation summary in
[`docs/VALIDATION.md`](../docs/VALIDATION.md); the corresponding reference fixtures are no longer
bundled.
