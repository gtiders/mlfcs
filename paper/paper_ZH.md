# MLFCS：基于 ASE 和 JAX 的对称性约化有限差分力常数

本文件是 JOSS 英文稿 [`paper.md`](paper.md) 的中文阅读版；正式投稿以英文稿为准。

## 摘要

原子间力常数描述晶体能量随原子位移的变化，是谐性声子，以及热膨胀、声子散射和
晶格热导率等非谐计算的核心输入。MLFCS 根据原子力重建这些张量。用户提供 ASE 结构，
并通过 ASE calculator 或外部流程计算力；MLFCS 负责对称性约化、有限位移生成、重建、
可选平移约束和格式导出。

MLFCS 不使用分阶位移程序，而用同一套参数化实现处理二阶及任意更高阶。三阶和四阶是
主要生产路径，更高阶张量可通过稀疏 HDF5 保存。软件支持 CPU，也可以在兼容 GPU 上
通过 JAX 加速笛卡尔张量操作。

## 软件需求

有限位移力常数不只是反复移动原子。程序必须识别晶体对称性和指标置换下等价的原子
团簇与张量分量，保证位移构型可复现，并使周期像和原子顺序从计算力一直保持到导出。
四阶、高阶和多组分晶胞还会迅速暴露稠密张量的内存问题。

phonopy/phono3py 提供成熟的谐性和三阶流程，ALAMODE 提供基于位移与回归的非谐晶格
动力学，hiphive 在对称团簇空间拟合力常数模型，ShengBTE 与 FourPhonon 分别使用三阶
和四阶相互作用计算输运。MLFCS 面向另一类具体需求：从任意 ASE 力源执行确定性的中心
有限差分、通过一个阶数参数扩展到 FC3 以上，并在不把力生成绑定到特定第一性原理程序
或势函数的前提下保持稀疏结果。

## 领域定位

MLFCS 是 phonopy、phono3py、ALAMODE 和 hiphive 的补充而非替代。ASE 作为 calculator
边界，使经典势、机器学习势和第一性原理适配器能共用同一计算对象。`sow()`/`reap()`
契约支持无法在 Python 进程内运行的调度系统与电子结构程序；稳定构型 ID 和计划哈希
能够发现缺失、重复、乱序或过期的力数据。

软件把递归的任意阶中心差分计划、对称性约化团簇张量和稀疏重建组合在一起。FC3/FC4
可导出 ShengBTE，FC2 可导出稠密 phonopy 格式，FC2/FC3 可与 phonopy/phono3py HDF5
互操作，更高阶使用通用 HDF5。兼容模式复现历史 thirdorder 周期像约定，默认格式则与
重建共享同一个对称闭合支撑域。

## 软件设计

对于 `n` 阶力常数，MLFCS 将其视为力对位移的 `n-1` 阶导数。递归中心模板生成带符号
的位移键；空间群操作、力常数指标置换和团簇稳定子将每个张量约化为独立笛卡尔参数。
程序只采样必要导数，再把参数展开到对称相关的稀疏团簇周期像。

声学求和规则在不可约轨道参数空间中作为严格受约束投影施加，而不是对最终张量做相对
补偿。小体系使用 Gram 矩阵零空间和稀疏 LSMR 精修，大体系直接使用矩阵无关稀疏 LSMR。
稠密张量只在用户请求时物化；连续稀疏数组、批量 JAX 变换、JIT、位移键去重和流式
导出共同控制运行时间与峰值内存。

API 不拥有力计算器。`run()` 串行调用用户提供的 ASE calculator，避免复制大型机器
学习势；`sow()` 返回供外部计算的有序 ASE 结构，`reap()` 校验并重建返回的力。科学
来源和并行执行因此仍由用户控制。

## 研究影响与验证

MLFCS 已公开开发并用于力常数和热输运工作流。3.0 版使用可复现测试层级，不再把旧版
一致性当作唯一判据。FC2/FC3 分别与二元 AlN 和多组分 K4As4Pt2 的 phonopy/phono3py
独立结果比较；3x3x3 Si 数据检查完整 VASP sow/reap 和 ShengBTE 流程；FC4 则与独立
JAX 四阶微分的 FCC Morse 解析能量比较，并验证位移减半时中心差分的二阶误差收敛。
参考数据同时记录来源、校验和、原子顺序适配及 ASR 开关对比。

持续集成在 Python 3.12 和 3.13 上运行公共 API、构建发行包，并串行执行科学基准以控制
内存。这为将力常数用于输运、非谐声子和温度相关有效谐性研究提供了可替换势函数的基础。
