# MLFCS：基于 ASE 和 JAX 的任意阶有限差分力常数

本文件是 JOSS 英文稿 [`paper.md`](paper.md) 的中文阅读版；正式投稿以英文稿为准。
作者为高一波（Yibo Gao），单位为中南大学物理学院。

## 摘要

原子间力常数描述晶体能量随原子位移的变化。二阶力常数决定谐性声子，三阶和四阶项
用于声子散射率、晶格热导率等计算。有限差分的概念很简单——移动原子并计算力——但
原子团簇、笛卡尔分量和位移组合的数量会随阶数迅速增长。

MLFCS 是一个从二阶到任意阶重建对称性约化力常数的开源 Python 库。它通过 ASE 接收
结构，并从用户选择的 ASE calculator 或外部电子结构工作流接收力。同一套阶数参数化
流程负责周期团簇枚举、对称性约化、递归中心有限差分、稀疏重建、可选平移不变性约束
和主流声子格式导出。三阶和四阶是主要生产路径，更高阶使用同一算法并可保留在通用
稀疏 HDF5 中。

## 软件需求

高阶有限差分同时面对三个问题：空间群、力常数指标置换和张量稳定子必须一致处理；
原子身份与周期像必须从位移生成一直保持到力收集和导出；高阶笛卡尔变换、完整力常数
数组及不恰当的完整 SVD 还可能在真正计算力之前耗尽内存。

机器学习势使这一问题更加明显。力计算变快以后，对称性处理和张量重建会占据更明显的
运行时间，而并行加载多个势函数实例会成倍增加内存。MLFCS 因此把资源效率作为科学
可计算性的组成部分：只保存对称性生成的稀疏团簇张量，以矩阵无关方式执行笛卡尔旋转，
去重等价位移任务，流式转换大文件，并默认串行调用进程内 calculator。JAX 在 CPU 或
兼容 GPU 上执行 JIT 和批量张量收缩，大规模稀疏约束则交给节省内存的 CPU 求解器。

## 领域定位

MLFCS 的技术起点是对 GPL 许可的 thirdorder 软件算法与工作流的参考和借鉴。具体包括
有限位移 FC3 的对称性约化、周期镜像约定和有序 `sow`/`reap` 流程。本文明确保留这一
来源关系，不把 FC3 方法表述成完全独立产生。MLFCS 在此基础上新增设计了阶数参数化的
ASE/JAX 架构、稀疏表示、受约束求和规则求解器，以及覆盖二阶至任意阶的可互操作 API。

phonopy/phono3py 提供成熟的谐性和三阶有限位移流程，ALAMODE 支持基于位移和回归的
非谐晶格动力学，hiphive 在对称团簇空间拟合力常数模型，ShengBTE 与 FourPhonon 使用
三阶和四阶相互作用计算输运。MLFCS 与这些软件互补，其明确定位是：从任意 ASE 力源
执行确定性的中心有限差分，用一个阶数参数覆盖不同张量秩，并在不绑定特定电子结构
程序或机器学习势的情况下保持稀疏结果。

MLFCS 可导出 phonopy FC2、phonopy/phono3py FC2/FC3 HDF5 和 ShengBTE FC3/FC4，
通用 HDF5 则保存更高阶结果。可选的随机有效谐性模块可以计算温度相关 FC2，但与
有限差分重建保持独立。

## 软件设计

对于 `n` 阶力常数，MLFCS 计算力对位移的 `n-1` 阶导数。递归中心模板生成带符号位移
键；空间群操作、全部相关指标置换和笛卡尔旋转构成等价团簇轨道；稳定子约束确定每个
轨道的独立笛卡尔基。返回力以后，采样导数直接重建为稀疏团簇周期像。

声学求和规则在不可约参数空间作为严格约束 `A p = 0` 施加。中等规模使用小 Gram
矩阵确定零空间，并用稀疏 LSMR 对原约束精修；较大体系直接使用稀疏 LSMR，避免稠密
分解。只有用户明确请求时才物化稠密张量，稀疏 HDF5 不需要完整高阶数组。

每个位移结构还携带稳定构型 ID、原子顺序、位移数组和完整计划哈希。返回力既可以
严格遵循生成顺序，也可以按 ID 乱序提交；缺失、重复、重排或过期数据会在重建前被
发现。这使同一个计算对象能够连接本地 ASE calculator、批处理调度器或 VASP 等外部
第一性原理程序，而无需把站点相关执行逻辑写进 MLFCS。

## 验证与资源友好执行

测试体系把数学单元测试与独立科学基准分开。FC2/FC3 分别与二元 AlN 和多组分
K4As4Pt2 的 phonopy/phono3py 结果比较；3x3x3 Si 基准覆盖完整的外部 VASP 力和
ShengBTE 导出流程；FC4 则由独立 JAX 实现对 FCC Morse 解析对势做四次微分，并验证
中心有限差分在步长减半时呈预期的二阶误差收敛。

性能从算法和算子层面论证，而不把解决不同拟合或有限位移问题的软件做整程序横向比较。
对称性约化与位移键去重避免不必要的力计算；矩阵无关张量作用避免构造
`3^n × 3^n` 笛卡尔表示矩阵；稀疏约束求解避免稠密分解。剩余高秩张量操作由 JAX 的
JIT、`vmap` 和批量收缩实现。同一套算子既能在 CPU 上运行，也能通过显式后端选项放到
兼容 GPU；团簇枚举和大型稀疏求解仍保留在 CPU。

存储表示本身可以提供无需比较不同端到端路线的可复现规模检查。NaS 五阶第一近邻烟雾
测试包含 1686 个稀疏团簇周期像，HDF5 约 789 KiB，而对应完整稠密张量的估算大小约为
243 GiB。持续集成在 Python 3.12 和 3.13 上运行，并串行执行科学基准，使正确性验证
不依赖高内存并行执行。

## 研究影响

MLFCS 面向已经拥有力生成器、但需要从位移结构可靠得到可互操作力常数的研究者。同一
公开工作流可以连接经典势、机器学习势和外部调度的第一性原理计算。任意阶表示还允许
研究者探索高阶相互作用，而不必为每个阶数建立新的固定代码路径。数据来源记录、冻结
力数据、校验和及可由第三方读取的导出文件，使结果可以在后续声子输运流程中审计和复用。
