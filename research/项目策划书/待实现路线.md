### 已完成并通过回归

- primitive site + exact integer translation $R$ 的 canonical sparse IFC；
- SymPy HNF quotient reduction、representative、cell index 和非对角超胞测试；
- 单一 reference supercell realization、collision-sum 和可辨识性检查；
- Wick→Taylor target-orbit dual-block intertwiner；
- Cartesian invariant 核的 `eigh`/QR/`solve` 标准化；
- Si、SnSe 和 Ba8Ga16Ge30 的拟合数值回归；
- space-group generator orbit prototype：FC2–FC5 不进入生产，FC6+ 保留为有价值候选；
- HNF reciprocal quotient 及 exact integer reciprocal labels，$q/-q$ 配对不再依赖浮点坐标舍入；
- Direct-Gram 和完整 SNF mapping 独立调研，当前结论均为不替换生产路径。

### 已实现但需要明确语义

- `cutoff=None` 是当前 reference supercell 对 exact-$R$ 交互的最大无周期像歧义半径，并从第一个歧义边界减去 $0.01$ Å。它不是无穷大 cutoff，也不是 ALAMODE/phonopy 的完整有限超胞 FC2 语义。
- KCl 验证表明，增大 source supercell 能改善 exact-$R$ 结果，但极性长程尾部仍需要解析静电分解。
- K4As4Pt2 SCPH 的末期频率变化停在约 $10^{-6}$ THz，未达到 $10^{-10}$ THz 阈值；这是待独立处理的固定点收敛问题。

## 2. 下一个物理优先项：谐偶极长程减力

实现边界和验收细节见[长程静电与短程力拟合](长程静电与短程力拟合.md)。本阶段只实现：

$$
F^{\mathrm{SR}}=F^{\mathrm{observed}}-F^{\mathrm{DD}},
$$

其中 $F^{\mathrm{DD}}$ 由 $Z^*$、$\epsilon^\infty$ 和 reference supercell 的周期 Ewald 模型生成。不在本阶段处理 writer 加回、多极或高阶非谐长程项。

## 3. signed displacement 对称约化开关评估

### 3.1 当前行为

当前生产路径已经通过 interaction orbit 和 Cartesian pivot 减少 displacement keys，但对每个 key 仍完整生成 $2^{n-1}$ 个中心差分 signed configurations。当前没有在这些正负构型之间再执行空间群轨道约化。

### 3.2 建议 API

为避免布尔参数语义不清，使用显式模式：

```python
calculation = ForceConstantCalculation(
    primitive,
    reference=reference,
    order=4,
    cutoff=5.0,
    signed_displacement_reduction="none",
)
```

允许值为：

- `"none"`：保持现有完整 stencil，作为默认和数值基线；
- `"symmetry"`：只使用能把 Cartesian 单位轴映射为 signed Cartesian 单位轴的 reference 空间群操作。

不引入 `auto`，不根据材料或计算器静默改变模式。

### 3.3 实现影响

1. `finite_difference/sampling.py`：将完整逻辑 configurations 与实际 evaluation representatives 分开，保存 representative-to-member 力变换。
2. `api.py`：`sow()` 只返回 representatives，`reap()` 校验较小的力数组后恢复完整逻辑力表。
3. `finite_difference/extrapolation.py`：每个步长 subplan 使用同一约化规则，外推 contraction 保持不变。
4. metadata 记录 `logical_configurations`、`evaluated_configurations` 和所用模式。

不需要修改 interaction/cluster/orbit 枚举、`CentralDifferenceStencil` 数学公式、IFC reconstruction、ASR、fitting、Wick/Taylor、HDF5 或 writer。

因此对核心物理架构的破坏性低，但对外部 `sow/reap` 调度协议的影响为中等：开启后构型数、稳定 ID 和回收力数组的长度都会变化。默认 `"none"` 可保证现有案例和外部调度不变。

### 3.4 代码量与难度

预计生产代码约 300–450 行：

- signed coefficient canonicalization 和精确重复合并：约 60–90 行；
- symmetry action 过滤、轨道和 force action：约 130–200 行；
- plan/API/extrapolation 接入和诊断：约 100–160 行。

测试和案例约 300–450 行，总量约 600–900 行。主要难点是：

- 只接受严格 signed-permutation Cartesian 旋转；
- 正确合成原子 permutation 和 Cartesian force rotation；
- 不假设 $F(-u)=-F(u)$；
- 确保 reference 原子重排和非对角超胞下结果不变；
- 区分精确相同位移的无条件合并与依赖计算器对称性的力恢复。

结论为 **可实现，但不应与长程静电或 orbit 重构同时实施**。建议在偶极减力数值核稳定后作为独立提交进行。完整数学推导见 `research/signed_displacements/DERIVATION.md`。

### 3.5 验收门槛

- `"none"` 模式的 sow 数量、ID、导数和 IFC 逐项保持现有基线；
- 严格对称解析势下，`"symmetry"` 与完整 stencil 在浮点舍入误差内一致；
- 对被省略构型进行抽查时，报告力协变残差；
- 对不能表示为 signed permutation 的旋转严格跳过，不做近似坐标匹配；
- FC2、FC3、FC4、重复导数轴、反演存在/不存在、非对角超胞和原子重排全部覆盖。
