# 长程静电与短程力拟合

## 1. 问题的本质

有限周期超胞直接观测到的谐力常数不是无限 primitive 晶格中每个 exact translation $R$ 的独立值，而是同一周期 residue 中所有平移像的和：

$$
\bar\Phi^S_{ab}([R])
=
\sum_{L\in\mathbb Z^3}\Phi_{ab}(R+LS).
$$

当力常数在 source supercell 的可辨识半径内已足够小时，可以把有限超胞观测稳定地解释为短程 exact-$R$ IFC。对 KCl 等极性离子晶体，偶极–偶极力常数存在缓慢衰减的长程尾部，不同 $R+LS$ 对单一有限超胞产生完全相同的观测列。数据能确定它们的和，但不能唯一确定如何将该和分配给各个 exact-$R$ 项。

普通 ridge 或 LASSO 可以从这个零空间中选出一个解，但该解取决于正则先验，不是由当前超胞数据唯一恢复的物理长程 IFC。

## 2. 锁定的物理分解

MLFCS 不用纯数学正则化猜测偶极尾部，而是将谐力常数写成：

$$
\Phi^{\mathrm{total}}
=
\Phi^{\mathrm{SR}}
+
\Phi^{\mathrm{DD}}(Z^*,\epsilon^\infty).
$$

$\Phi^{\mathrm{DD}}$ 是由 Born 有效电荷 $Z^*$ 和高频电子介电张量 $\epsilon^\infty$ 确定的周期偶极–偶极模型，$\Phi^{\mathrm{SR}}$ 是交给 exact-$R$ IFC 构造器的快速衰减部分。

对 reference supercell 中的位移 $u$，先计算：

$$
F^{\mathrm{DD}}(u)=-\Phi^{\mathrm{DD},S}u,
$$

再构造拟合目标：

$$
F^{\mathrm{SR}}(u)
=
F^{\mathrm{snapshot}}(u)
-F^{\mathrm{reference}}
-F^{\mathrm{DD}}(u).
$$

固定 $Z^*$ 和 $\epsilon^\infty$ 的近似只移除线性谐偶极项。它不移除 $Z^*$ 或 $\epsilon^\infty$ 对位移的导数，因此不能声称 FC3 和 FC4 中的所有长程静电贡献已被消除。

## 3. 待实现数据对象

解析长程模型不写成有限的 `SparseOrderForceConstants`，而是作为独立数据与短程 IFC 关联：

```python
DipoleParameters(
    born_effective_charges,  # (n_primitive, 3, 3)
    dielectric,              # (3, 3)
)

DipoleForceCorrection(
    primitive,
    reference,
    born_effective_charges,
    dielectric,
    *,
    symprec=1e-5,
    ewald_tolerance=1e-12,
)
```

顶层操作保持显式：

```python
correction.force_constants()
correction.forces(displacements)
correction.subtract(displacements, forces)
```

`force_constants()` 返回当前 reference 原子顺序下的周期化偶极 FC2，形状为 `(n_supercell, n_supercell, 3, 3)`。`forces()` 和 `subtract()` 使用 `(n_frames, n_supercell, 3)` 数组，不修改用户传入的数组或 ASE structures。

## 4. 待实现数值核

实现周期 Ewald 偶极 FC2：

$$
\Phi^{\mathrm{DD},S}
=
\Phi^{\mathrm{real}}
+
\Phi^{\mathrm{reciprocal}}
+
\Phi^{\mathrm{self}}.
$$

数值核必须：

- 支持一般非对角 supercell matrix；
- 使用 `StructureRelation` 将 primitive Born tensor 映射到用户 reference 顺序；
- 根据误差阈值选择 Ewald 实空间和倒空间截断，不使用固定 27 镜像；
- 缓存同一 primitive/reference/电学参数的 $\Phi^{\mathrm{DD},S}$；
- 验证交换对称性和声学求和残差；
- 统一使用 ASE 的 Å 与 eV 单位约定。

核心运行时不依赖 phonopy。phonopy 的 Gonze–Lee 数据集只作为独立数值对照，不调用其非公开内部方法作为 MLFCS 生产实现。

## 5. 输入与物理验证

- Born tensor 形状必须是 `(n_primitive, 3, 3)`，顺序严格对应显式 primitive；
- $\epsilon^\infty$ 必须是有限、对称且正定的 $(3,3)$ 高频介电张量；
- reference 必须是 primitive 的合法整数超胞；
- 公共 API 接受无量纲 $Z^*$ 和 $\epsilon^\infty$，输出使用 eV/Å 和 eV/Å$^2$；
- 显式报告 Born 电中性残差
  $$
  \Delta_Z=\left\|\sum_\kappa Z_\kappa^*\right\|,
  $$
  默认不静默对称化或投影用户输入。

## 6. 拟合接入边界

待实现 API：

```python
result = fitter.fit(
    structures,
    force_correction=correction,
)
```

该功能只改变目标向量：

$$
y\longrightarrow y-y_{\mathrm{DD}}.
$$

设计矩阵 $X$、Wick covariance、orbit、exact-$R$ key、ASR 零空间、Gram 和 solver 均保持不变。因此 $G=X^TX$ 不变，只有：

$$
b=X^Ty
\longrightarrow
X^T(y-y_{\mathrm{DD}}).
$$

有限差分可显式调用同一 `subtract()` 后将短程力传入 `reap()`；第一阶段不在 `reap()` 中加入隐式行为。

拟合结果必须保留 $Z^*$、$\epsilon^\infty$、原子顺序、Ewald 约定和 `long_range_orders_removed = [2]`，防止将短程 FC2 误当为完整 FC2。

## 7. 验收标准

1. KCl/NaCl 的 $\Phi^{\mathrm{DD},S}$ 和随机位移力与 phonopy Gonze–Lee 参考在 FP64 容差内一致。
2. 交换对称、ASR、非对角超胞和 reference 原子重排测试通过。
3. 零 Born tensor 必须严格产生零修正。
4. KCl 64 与 512 原子 source supercell 在共同可辨识支撑上得到更接近的 $\Phi^{\mathrm{SR}}$。
5. 开启修正前后 orbit、参数数、design 和 $X^TX$ 不变。
6. 结果不得将谐偶极修正宣称为多极或高阶长程修正。

## 8. 实现顺序

1. `DipoleParameters` 及严格输入验证。
2. 周期 Ewald 偶极 FC2 数值核。
3. reference-order FC2 与批量 force contraction。
4. phonopy 独立数值对照和 KCl 大/小超胞验证。
5. `ForceConstantFitter.fit(force_correction=...)` 显式接入。
6. 结果对象和 HDF5 保存长程模型参数及 provenance。
7. 有限差分显式减力案例。

在上述验证完成前，不实现 writer 加回，也不扩展到动力学四极或更高多极。

## 9. 现有软件的参考边界

hiPhive 没有自己的偶极 Ewald 数值核；其公开教程调用 phonopy 生成 Gonze 长程 FC2，再从训练力中扣除对应线性力。这一“先减力、再拟合短程模型”的物理分层是本计划的参考，但 MLFCS 不依赖其调用的 phonopy 内部方法。参见 [hiPhive 长程力教程](https://hiphive.materialsmodeling.org/advanced_topics/long_range_forces.html)。

ALAMODE 的 Ewald 模式也将超胞谐力常数分成短程与偶极–偶极部分。其处理位于声子后处理阶段，不改变本计划首先只实现拟合前减力的范围。参见 [ANPHON 长程修正理论](https://alamode.readthedocs.io/en/latest/anphondir/formalism_anphon.html)。
