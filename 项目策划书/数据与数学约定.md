# 数据与数学约定

## 1. 结构关系

primitive 用 $A$ 表示晶格矩阵，reference supercell 用整数矩阵 $S$ 表示：

$$
A_{\mathrm{super}} = S A_{\mathrm{primitive}}.
$$

结构关系保存每个 reference 原子的 primitive site、整数平移、原子顺序和超胞商群索引。整数行列式 $|\det S|$ 等于 reference 中包含的 primitive 原胞数。

## 2. 稀疏力常数

第 $n$ 阶物理条目写作：

$$
\Phi^{(n)}_{\kappa_1\ldots\kappa_n}(0,R_2,\ldots,R_n).
$$

内部稀疏记录由以下三部分组成：

```text
sites                        (K, n)
translation_representatives  (K, n - 1, 3)
tensors                      (K, 3, ..., 3)
```

张量分量始终采用笛卡尔坐标。支撑域由条目存在性表示，不能用“张量数值接近零”推断条目是否存在。

## 3. 周期平移与 residue

对于超胞矩阵 $S$，整数平移按商群等价：

$$
R \sim R + nS, \qquad n \in \mathbb{Z}^3.
$$

residue 只用于整数晶格等价性和 reference 原子查找。它不承担最近镜像、Wigner--Seitz 镜像选择或格式专用的 27 镜像编码。

## 4. Taylor 能量约定

位移记为 $u$ 时，能量展开为：

$$
U = U_0 + \sum_{n\ge 2}\frac{1}{n!}\Phi^{(n)}u^n.
$$

有限差分和拟合得到的是 Taylor 力常数。SSCHA 与 SCPH 输出的是温度相关的有效二阶力常数，不把高阶输入自动附加到返回对象中。

## 5. 储存与物化

核心存储优先保持稀疏。只有目标格式或明确的用户调用要求时，才将指定阶数物化为稠密数组。任何稠密化都必须显式知道 primitive site 和 reference atom index 的映射，不能直接把两套索引当作同一含义。
