# MLFCS 项目总览

## 1. 项目定位

MLFCS 是一个面向晶格动力学和热输运的力常数计算平台。项目的核心任务是把有限差分、机器学习势函数、轨迹拟合以及有限温度自洽方法统一到同一套结构关系、周期标签、稀疏力常数和格式导出模型中。

项目的基本输出是带有明确结构语义的 Taylor 力常数。计算结果可以继续交给声子、三声子热输运、四声子热输运和其他后处理程序。

## 2. 解决的问题

高阶力常数计算同时受到以下问题限制：

- 位移构型数量随阶数快速增加；
- 超胞原子数和张量维度造成存储压力；
- 原子顺序、周期平移和不同软件格式之间容易发生语义错位；
- 对称性、平移不变性、旋转求和规则和拟合误差可能相互耦合；
- 有限温度有效谐波力常数需要与零温 Taylor 力常数清楚区分。

MLFCS 通过稀疏物理标签、对称约化参数化、流式 Gram 拟合、统一周期几何和通用导出视图处理这些问题。

## 3. 用户工作流

项目从上到下遵循以下主线：

1. 用户准备 primitive 和 reference supercell；
2. 结构层建立原胞、超胞、原子标签和整数平移的对应关系；
3. 周期几何层确定邻居、截断和周期距离；
4. 有限差分或拟合层生成 Taylor 力常数；
5. 约束层施加 ASR、旋转求和规则或 Huang 条件；
6. SSCHA 或 SCPH 生成只含有效 FC2 的有限温度结果；
7. IO 层将同一内部结果转换为 HDF5、phonopy、ShengBTE 或 ALAMODE 表示；
8. examples 保存可复现实验、第三方对照和后处理结果。

## 4. 明确边界

项目当前不自动改变 primitive 定义，不静默重排用户 reference，不把不同平移晶格投影为近似等价结构，也不把有限温度有效 FC2 与输入 FC3、FC4 混合保存。

导出时可以更换严格等价的 primitive 或 supercell 表示，但不得改变原子数、体积、平移子晶格或包含的原胞数。整体笛卡尔刚性旋转暂不作为结构转换操作。

## 5. 先写什么

自顶向下维护项目文档时，优先级应为：

1. 项目目标、边界和用户工作流；
2. 模块分层及依赖方向；
3. 结构、周期性和力常数的数据约定；
4. 计算方法与数学公式；
5. 公共 API 和输入输出契约；
6. 实施阶段、验收指标和回滚边界；
7. 测试、examples 和第三方验证规范；
8. 性能、缓存、并行和故障诊断。

只有在这些内容稳定后，才适合补充单个函数的实现说明或某个材料的运行记录。
