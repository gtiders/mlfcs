# Si thermal conductivity with extrapolated FC3

This calculation uses the existing [`fc2`](../fc2/README.md) FC2 and the
zero-displacement extrapolated FC3 from
[`fc3-extrapolated`](../fc3-extrapolated/README.md). Run both first. The
explicit supercell generated by the extrapolation workflow is passed to
phono3py with an identity supercell matrix and `primitive_matrix="auto"`, so
phono3py identifies the primitive cell from that supercell.

Run from this directory:

```bash
uv run --project ../../../.. --with phono3py python run.py
```

The settings match the regular conductivity case: a $10\times10\times10$
mesh, isotope scattering, and temperatures from 300 K through 900 K in 100 K
increments. `run.log` captures stdout, stderr, and any traceback. The HDF5
file contains the full conductivity result; `thermal-conductivity.json`
records the inputs, phono3py version, and conductivity tensor values.

Using phono3py 4.4.0, the diagonal components and their change from the
regular FC3 workflow were:

| Temperature (K) | Regular FC3 ($\kappa_{xx}$) | Extrapolated FC3 ($\kappa_{xx}$) | Change |
|---:|---:|---:|---:|
| 300 | 84.338 | 84.389 | +0.0611% |
| 400 | 61.159 | 61.196 | +0.0605% |
| 500 | 48.264 | 48.294 | +0.0604% |
| 600 | 39.966 | 39.990 | +0.0603% |
| 700 | 34.148 | 34.168 | +0.0603% |
| 800 | 29.830 | 29.848 | +0.0603% |
| 900 | 26.493 | 26.509 | +0.0603% |

The cubic Si tensor is isotropic here, so the $xx$, $yy$, and $zz$ components
agree to numerical precision. The small shift reflects only the FC3
extrapolation; FC2 and the phono3py settings are unchanged.
