# Ba8Ga16Ge30 势函数来源与致谢

`fcp_2body-5.4_4.35_4.35_least-squares.fcp` 来自 hiPhive 公开的
Ba8Ga16Ge30 clathrate thermal-conductivity 教学案例。该文件是上游拟合好的
force-constant potential；本教学案例不重新训练它。

请在使用、复现或再分发本案例时保留 hiPhive 上游案例、相关论文及其原始许可证中的
致谢和引用信息。该 FCP 的构造采用 FC2、FC3、FC4 的截断半径分别为 5.4、4.35、
4.35 Å，并使用最大 2-body 相互作用。
